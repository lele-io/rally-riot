# Rally Riot

Fast, chaotic badminton × tennis in the browser — 1v1, 2v2 and 3v3. Shuttle-and-net rallies with tennis power and spin.

**Play:** https://lele-io.github.io/rally-riot/

Controls: **WASD** move · **Space** jump · **Left click** swing (hold to charge a power swing) · **Q** dash (farther in mid-air) · **Mouse** aims.

Built with Three.js, Rapier and Vite. Models are made in Blender (`blender/build_models.py`).
